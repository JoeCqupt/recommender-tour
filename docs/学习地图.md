# 推荐系统学习地图:从入门到精通

> 这份地图回答一个问题:**为了"精通"推荐系统,我该按什么顺序学什么。**
> 每一阶段都同时沿**算法线 / 系统线 / 评估线**推进。阶段产出都落在本仓库里,可用 `git tag` 切换回看。

---

## 0. "精通"的标准

> **精通 = 能独立设计一个推荐系统的骨架 + 能读懂经典论文 + 能诊断线上效果问题。**

不是"会调库",而是"知道每个部件为什么存在、坏了怎么查"。下面的阶段划分都服务于这个标准。

---

## 1. 三条主线

```text
算法线:  统计(CF) ──► 学习(MF/BPR) ──► 特征交叉(FM/DeepFM) ──► 序列/深度
系统线:  单模型   ──► 召回+精排   ──► 多级漏斗            ──► 服务化
评估线:  离线指标 ──► 召回率/覆盖率/多样性 ──► 线上 A/B/EE
```

每进入一个新阶段,先看它在三线上的位置。

---

## 2. 阶段总览

| 阶段 | 主题 | 一句话 |
|---|---|---|
| **1** | 范式 + 离线评估 | 推荐到底在算什么:打分、排序、评估 |
| **2** | 隐式反馈 + 学习排序 | 为什么"评分准"≠"排得前",BPR 怎么解决 |
| **3** | 系统架构:召回 + 精排 | 物品太多怎么办:多级漏斗 + 向量召回 |
| **4** | CTR 估计:特征与模型 | 从 ID embedding 到特征交叉与深度模型 |
| **5** | 工程与服务 | 把算法装进一个能上线的推荐服务 |
| **6** | 论文与前沿 | 带着手感精读经典论文 |

---

## 3. 各阶段详解

### 阶段 1:范式 + 离线评估 ✅

- **核心问题**:推荐到底在算什么?
- **概念**:打分/排序范式、记忆型(CF/ItemCF)vs 模型型(MF)、倒排索引、余弦相似度、隐空间、SGD 三旋钮(`lr`/`reg`/`INIT_STD`)、HR@K / NDCG@K / RMSE、leave-one-out 切分。
- **产出**:`ItemCF` + `MatrixFactorization` + 离线评估框架 + k=2 可视化教程。
- **掌握标准**:能手写基础召回/排序算法,能识别"指标好看但没用"的陷阱。

### 阶段 2:隐式反馈 + 学习排序 ✅

- **核心问题**:为什么"评分预测准"不等于"排序排得前"?
- **概念**:目标错配、隐式反馈(≥4.0 视为正样本)、成对排序(BPR)、负采样、sigmoid 损失、`sigmoidNeg` 作为误差信号、time-split 评估。
- **产出**:`BprMF`(三方拉扯 update)+ 隐式评估。
- **掌握标准**:能说清 pointwise 与 pairwise 损失的区别,能调负采样。

### 阶段 3:系统架构 —— 召回 + 精排 ✅

- **核心问题**:物品太多,模型不可能每次全库打分,怎么办?
- **概念**:多级漏斗(召回→粗排→精排→重排)、多路召回、**向量召回与 ANN**、**召回率天花板**、候选集大小 / 召回率 / 延迟的三方权衡。
- **产出**:`Recall` 抽象 + `PopularRecall`/`VectorRecall`/`MultiRecall` + `TwoStageRecommender` + 单级 vs 两级实测对比。
- **掌握标准**:能说清"召回漏掉的,精排永远救不回来";能画出一个多路召回的架构图。

### 阶段 4:CTR 估计 —— 特征与模型 ← 当前

- **核心问题**:光有 ID embedding 不够,怎么用上"用户/物品/上下文"的特征?
- **概念**:特征工程、特征交叉(FM → Wide&Deep → DeepFM)、用户行为序列建模(DIN / 序列推荐)、多目标(CTR/CVR/时长)。
- **产出**:手写 FM(Java 可行)+ 理解 DeepFM / DIN 的结构与动机。
- **掌握标准**:能说清 FM 相比 MF 多解决了什么;能读懂 DeepFM 的"浅层+深层"双路结构。

### 阶段 5:工程与服务

- **核心问题**:离线训好的模型,怎么变成一个真实的线上服务?
- **概念**:离线训练 → 模型导出 → 在线 serving;特征存储 / 实时特征 / 样本拼接;冷启动;**探索与利用(EE)**;A/B 实验;**离线指标 ≠ 线上指标**。
- **产出**:一个能跑的迷你推荐服务(导出向量 + 召回 + 排序 + Top-K)。
- **掌握标准**:能画出"离线 / 近线 / 在线"的数据流;能设计一个 A/B 实验。

### 阶段 6:论文与前沿

- **核心问题**:怎么读懂并判断一篇推荐论文能不能落地?
- **概念**:读论文的方法(先动机与贡献,再公式)、经典脉络。
- **产出**:精读 5–8 篇:MF、BPR、Item-based CF、NCF、YouTube DNN、DIN、双塔、SASRec。
- **掌握标准**:能在一页纸内讲清一篇论文"为什么提出、核心做法、适用边界"。

---

## 4. 语言边界(重要约定)

| 阶段 | 语言 | 理由 |
|---|---|---|
| 1–3 | **纯 Java,零第三方依赖** | 亲手摸到每个梯度、每种数据结构,不被框架掩盖 |
| 4 起 | **Python**(深度学习模型) | 深度模型手写在 Java 里成本过高,90% 时间会花在写矩阵库而非学推荐 |

原则:**算法精髓用 Java 手写吃透,现代深度模型用 Python 读懂结构并实践。**

## 5. 怎么用这份地图

- 每进入一个新阶段,先回答该阶段的"核心问题",再动手。
- 每个阶段结束时:补 `docs/算法实现详解.md` 对应章节、更新 `README.md`、打 `stage-N` tag。
- 卡住时回到三主线,问自己:我卡的是算法、系统还是评估?
