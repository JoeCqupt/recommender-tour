# 推荐系统入门:从一行代码到一个能上线的系统

> 一本写给 **Java 后端/CRUD 工程师**、第一次接触推荐系统的**手写实践书**。
> 全书零第三方依赖,纯 Java,每一行公式都指到源码行号。

---

## 这本书是什么

一句话:**带你把推荐系统从"数学符号"一路搭到"召回 + 精排的两级架构",全部亲手写一遍。**

它不假设你会高等数学,也不假设你懂机器学习。它只假设你:

- 写过 Java(知道 `for`、`Map`、`List` 是什么);
- 对"向量"有模糊印象(其实只需要知道它是一排数);
- 愿意打开源码,对着书一行行看。

如果你曾经被"损失函数""梯度下降""隐空间"这些词劝退过,这本书就是为你写的。

## 怎么读这本书

**第一遍:按编号顺序读。** 章与章之间有严密的依赖关系——数学是地基,ItemCF 是最简单的推荐,MF 在它之上引入"训练",BPR 修正 MF 的目标,评估和两级架构是工程收尾。跳着读会断链。

```text
第 1 部  数学够用就好        ← 从符号到梯度,20 分钟
第 2 部  推荐第一课 ItemCF    ← 最简单的推荐:数共现
第 3 部  从统计到学习 MF      ← 第一次出现"训练"
第 4 部  隐式反馈与排序 BPR   ← 修正 MF 的目标错配
第 5 部  评估                ← 怎么判断好坏
第 6 部  两级架构             ← 召回 + 精排
第 7 部  进阶路线图           ← 下一站去哪
附录     A 可视化 / B 踩坑 / C 自测 / D 参考
```

**第二遍:遇到不懂就回查。** 书里的公式下方都有 **「🔤 公式翻译」** 小卡片,把公式读成人话并指到代码行。忘了某个符号,回 [`part-01-math.md`](part-01-math.md) 的速查卡。

**每读完一部,做附录 C 对应的自测题。** 做不出来说明没读透,回头再看。

## 技术象限:你写的每样东西属于哪一类

很多初学者以为"推荐系统 = 深度学习"。其实完全不是。这条技术链是**层层包含**的:

```text
统计/规则        机器学习           神经网络              深度学习
(数数,不训练)  ⊂  (学参数)  ⊂  (embedding+激活+反向传播) ⊂  (多层堆叠)

另外还有一条独立的线:⚙️ 工程/系统(架构、指标、服务)—— 它不是"模型",而是把模型跑起来的东西。
```

| 标签 | 含义 | 推荐系统里的例子 | 本仓库对应 |
|---|---|---|---|
| 🟢 统计 / 规则 | 靠数数或人工规则,不训练参数 | ItemCF、热门榜 | `ItemCF`、`PopularRecommender` |
| 🔵 机器学习 | 用数据 + 优化自动学出参数 | 矩阵分解、逻辑回归、GBDT | `MatrixFactorization` |
| 🟣 神经网络 | embedding + 权重 + 激活 + 反向传播 | 无隐藏层的 MF/BPR、FM | `BprMF`(最小神经网络) |
| 🟠 深度学习 | 多层神经网络 | DeepFM、Wide&Deep、DIN、双塔、SASRec | 阶段 4/6 |
| ⚙️ 工程 / 系统 | 不是模型;是模型跑起来所需的架构、指标与服务 | 召回+精排架构、评估指标、模型导出 | `Metrics`、`Recall`、`EmbeddingStore` |

> **两个可能颠覆你认知的事实:**
> 1. **你从第 3 部就已经在做机器学习了。** MF/BPR 的"损失 + 梯度下降",正是机器学习的核心动作。
> 2. **你写的 MF/BPR 已经是神经网络了。** 它们只是"没有隐藏层"的神经网络:`p_u·q_i` 是线性层、`σ` 是激活函数、SGD 就是反向传播。
>
> 也就是说:第 1–6 部你已经在用 🔵🟣 了;真正的新东西 🟠 从第 7 部的路线图开始。

每一部的标题后都带一个这样的标签,你一眼就能知道"这一节是在数数、在训练,还是在搭架构"。
