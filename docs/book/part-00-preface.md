# 序言:这本书想帮你跨过什么

> 一本写给有 Java 后端经验、第一次接触推荐系统的你的手写实践书。

## 0. 写给谁

如果你符合下面任意一条,这本书就是为你写的:

- 你会写 CRUD:增删改查、分页、缓存、索引,手到擒来;
- 但一到"推荐算法",公式、损失、梯度、隐空间,全都看不懂;
- 你怀疑自己做不了推荐系统,因为"数学太差";
- 你想要的不只是"会用库",而是"知道每个部件为什么存在"。

**先给你吃一颗定心丸:** 推荐系统的入门,90% 靠的是工程直觉,10% 才是那点数学。而那 10%,本书只用第 1 部、20 分钟就给你讲完。你不需要成为数学家。

## 1. 这本书的学习方式:手写,零依赖

本书配套的代码仓库 **不含任何第三方库**——没有 Spring、没有 Guava、没有 NumPy。所有算法用纯 Java 从零手写。

**为什么这么"自虐"?**

因为推荐系统的精髓藏在梯度、相似度、堆结构这些细节里。用框架时,这些细节被一行 `model.fit()` 盖住了,你学到的只是"API 调用"。手写一遍,你会亲眼看到:

- 相似度是怎么从"共现次数"数出来的;
- 梯度下降是怎么一行行把参数挪到最优的;
- Top-N 是怎么用小顶堆在 O(n log n) 里选出来的。

**看清每个齿轮怎么转,之后再用框架,你才知道它在替你做什么。**

## 2. 语言边界:前六部用 Java,之后换 Python

这是本书一条重要的约定:

| 部分 | 语言 | 理由 |
|---|---|---|
| 第 1–6 部 | **纯 Java,零第三方依赖** | 亲手摸到每个梯度、每种数据结构,不被框架掩盖 |
| 第 7 部起(进阶) | **Python**(深度学习模型) | 深度模型手写在 Java 里成本过高,90% 时间会花在写矩阵库而非学推荐 |

原则:**算法精髓用 Java 手写吃透,现代深度模型用 Python 读懂结构并实践。**

前六部让你"看清机制",第七部之后让你"站到巨人的肩膀上"。两者缺一不可。

## 3. 三条主线:推荐系统到底在学什么

一提到推荐系统,新手常以为只是"一堆算法"。其实它同时沿三条线推进:

```text
算法线:  统计(CF) ──► 学习(MF/BPR) ──► 特征交叉(FM/DeepFM) ──► 序列/深度
系统线:  单模型   ──► 召回+精排   ──► 多级漏斗            ──► 服务化
评估线:  离线指标 ──► 召回率/覆盖率/多样性 ──► 线上 A/B/EE
```

本书的前六部,正好把前两条线从左边推到中段,第三条线从头讲到能用的程度:

- **算法线**:第 2 部 ItemCF(统计)→ 第 3 部 MF(学习)→ 第 4 部 BPR(排序学习)。三步走完"从数数到训练"。
- **系统线**:第 6 部把单模型升级成"召回 + 精排"的两级架构。
- **评估线**:第 5 部讲清 HR@K / NDCG@K / RMSE / 覆盖率,以及"离线指标好看不等于有用"的陷阱。

## 4. 阶段总图:本书覆盖了"精通"路的哪一段

推荐系统的完整学习可以分成六个阶段。本书覆盖前三个,并给你第四阶段之后的路线图:

| 阶段 | 主题 | 一句话 | 涉及技术 | 本书位置 |
|---|---|---|---|---|
| **1** | 范式 + 离线评估 | 推荐到底在算什么:打分、排序、评估 | 🟢 统计 → 🔵 机器学习 | 第 1–3、5 部 |
| **2** | 隐式反馈 + 学习排序 | 为什么"评分准"≠"排得前",BPR 怎么解决 | 🔵 机器学习 · 🟣 神经网络 | 第 4 部 |
| **3** | 系统架构:召回 + 精排 | 物品太多怎么办:多级漏斗 + 向量召回 | ⚙️ 工程/系统 | 第 6 部 |
| **4** | CTR 估计:特征与模型 | 从 ID embedding 到特征交叉与深度模型 | 🔵🟣 机器学习 · 🟠 深度学习 | 第 7 部(路线图) |
| **5** | 工程与服务 | 把算法装进一个能上线的推荐服务 | ⚙️ 工程/系统 | 第 7 部(路线图) |
| **6** | 论文与前沿 | 带着手感精读经典论文 | 🟠 深度学习为主 | 第 7 部(路线图) |

**"精通"的标准是什么?** 不是"会调库",而是:

> **能独立设计一个推荐系统的骨架 + 能读懂经典论文 + 能诊断线上效果问题。**

也就是"知道每个部件为什么存在、坏了怎么查"。这本书的每一部都服务于这个标准。

## 5. 一个心理准备

读完这本书,你**不会**成为推荐算法专家,也**不会**立刻做出一个比抖音更好的推荐。但你会得到一个扎实的东西:

> **一套完整的心智模型。** 看到任何一个推荐系统,你能说出它由哪几块组成、每块在干什么、可能坏在哪;看到任何一个新算法,你能把它归到"统计/学习/网络/系统"的哪一类里,并猜到它的动机。

这东西比记住十个算法名值钱得多。
