> **先读这一部,再读任何算法。** 它不讲证明,只干一件事:**把每个数学符号翻译成人话和代码**。
> 约 20 分钟读完。之后遇到不懂的公式,随时回来查。

**前置知识**:无。会写 Java 的 `for` 循环就够。
**读完你能**:看懂后面每一部的公式在说什么,不再被符号吓退。
**对应技术象限**:🔵 机器学习(损失、梯度、参数这套语言就是机器学习本身)。

## 0. 先破一个恐惧:你怕的不是数学,是符号

同一个事情,可以有三种写法:

| Java 写法 | 人话 | 数学写法 |
|---|---|---|
| `for (int f=0; f<k; f++) s += a[f]*b[f];` | "把两个数组对应位置相乘再全部加起来" | `s = Σ a_f · b_f` |
| `double[] p = new double[100];` | "一排 100 个数" | `p ∈ ℝ^100` |
| `p[f] += 0.02 * (误差 - 0.01*p[f]);` | "把第 f 个数朝让误差变小的方向挪一点点" | `p_f ← p_f + η(∂L/∂p_f)` |

**看出来了吗?** 数学公式不是"更高级的知识",它是**"人话和代码的压缩写法"**。你看不懂公式,通常只是没人告诉你"这个符号对应哪一行代码"。这部就是来补这个的。

## 1. 五个基础零件

推荐算法里 95% 的公式,只用到下面五个零件。

### 1.1 向量(vector)—— 就是一排数

```
p_u = [0.5, -0.2, 0.8, ...]            ← 数学写法
double[] p = {0.5, -0.2, 0.8, ...};    ← Java 写法
```

- `p_u` 里的 `u` 只是个**标签**(第 u 个用户),不是"乘以 u"。就像 `userMap.get(u)`。
- 下标 `p_f` 表示"第 f 个数",等价于 `p[f]`。
- 维度 k=100 就是"这排数有 100 个"。

在仓库里:`MatrixFactorization.java` 的 `p[nu][k]`、`q[ni][k]` 就是一堆向量。

### 1.2 点积(dot product)—— 对应相乘再相加

```
p · q = p₁q₁ + p₂q₂ + ... + p_k q_k
```

**它衡量两个向量的"方向有多一致"**:完全同向时最大,垂直时为 0,反向时为负。所以推荐系统拿它当**相似度 / 喜好分**。

它就是这段代码(`MatrixFactorization.java:111-117`):

```java
double s = 0;
for (int f = 0; f < a.length; f++) s += a[f] * b[f];
return s;
```

> **生活比喻**:两个人口味问卷,每道题都打 0~1 分。点积 = 把每题两人分数相乘再相加。同好的人每题都高,总和就大。

### 1.3 求和符号 Σ(sigma)—— 一个 for 循环

```
Σ_{i ∈ I_u} sim(i, c)
```

读作:"对用户 u 历史里的每个物品 i,把 sim(i,c) 加起来"。翻译成 Java 就是:

```java
for (long i : historyOf(u)) total += sim(i, c);
```

在仓库里:`ItemCF.java:108` 的 `score.merge(cand, nb.getValue(), Double::sum)` 就是这个 Σ。

### 1.4 参数 θ(theta)—— 你可以拧的旋钮

机器学习 = **"先猜一组参数,再一点点拧到最好"**。

- `p_u`、`q_i`、`b_u`、`b_i` 全是**参数**;它们的取值不是算出来的,是**训练调整出来的**。
- 数学上爱把它们统称 `θ`(= 所有旋钮的集合),方便写通用公式。

> **生活比喻**:一台有很多旋钮的老收音机,你想调到最清晰的频道。你听一下(算损失),再拧一点(更新参数),反复来。

### 1.5 下标、上标、希腊字母速查

| 符号 | 怎么读 | 意思 |
|---|---|---|
| `p_u` | p 下标 u | "第 u 个用户的向量",u 是标签 |
| `p_u · q_i` | p 点乘 q | 两个向量点积 |
| `η` (eta) | 伊塔 | 学习率,就是代码里的 `lr` |
| `λ` (lambda) | 兰姆达 | 正则系数,就是代码里的 `reg` |
| `μ` (mu) | 缪 | 全局平均分 |
| `‖p‖²` | p 的模平方 | 把向量每个数平方再相加 = `Σ p_f²`,用来衡量"向量有多大" |
| `σ(x)` | sigma | sigmoid 函数(见 §4) |
| `≈ == ≥ ≤` | | "约等于 / 等于 / 大于等于 / 小于等于" |

看到希腊字母**别慌**,它们只是"某个数的代号",和 `int count` 里的 `count` 一个性质。

## 2. 机器学习的三个核心词

所有"训练",都逃不出这三步循环:**算损失 → 求梯度 → 更新参数**。

> **🏷️ 这些零件属于哪个象限?** 损失、梯度、参数、学习率、正则——这套语言就是 **🔵 机器学习**。而 MF/BPR 那种"embedding + 激活 + 反向传播"的模型,同时又属于 **🟣 神经网络**(它们是"没有隐藏层"的神经网络)。**换句话说:你在读这一节的时候,已经在学机器学习了。**

### 2.1 损失 L(loss)—— 一个分数,越小越好

损失是**一个数**,衡量"模型现在错得多离谱"。训练的目标就是把它压小。

| 场景 | 损失 | 人话 |
|---|---|---|
| 评分预测(MF) | `L = (真实分 - 预测分)²` | 预测离真实越远,罚得越狠(平方放大) |
| 排序(BPR) | `L = -ln σ(x_ui - x_uj)` | 正样本没排到负样本前面的可能性越高,罚得越狠 |

> **生活比喻**:考试扣分。你答题(预测),老师按错得多少给扣分(损失)。分数越低=答得越好。

**为什么用平方?** 因为 `(真实-预测)` 有正有负,直接加起来会抵消;平方后都变正,还顺带"错得越多罚得越狠"。

### 2.2 梯度 ∂L/∂θ —— "坡往哪边、有多陡"

梯度回答一个问题:

> **如果我把某个旋钮拧大一点点,损失会变大还是变小?变多少?**

- 结果是**正数** → 拧大它会**增加**损失,那应该拧**小**;
- 结果是**负数** → 拧大它会**减小**损失,那就拧**大**。

> **生活比喻**:你蒙着眼站在山上,想知道往哪走最快到谷底。你用脚探一下周围地面的坡度(梯度),就知道"这边陡、朝这边下"。

**你不需要自己算梯度**——所有算法的梯度公式已经被写进代码里了。你的任务是**看懂它在说什么**(往哪拧),不是**重新推导它**。

### 2.3 梯度下降 θ ← θ − lr·(∂L/∂θ) —— 朝下坡挪一小步

把上面的结论合起来:**每个旋钮朝"让损失变小"的方向挪一小步**,反复几千几万次。

```
参数 ← 参数 + 步长 × (让损失变小的方向)
```

写成代码就是你在 MF/BPR 里见到的那一行行更新(`MatrixFactorization.java:97`):

```java
bU[u] += lr * (e - reg * bU[u]);
```

拆开看:

| 部分 | 是什么 | 人话 |
|---|---|---|
| `lr`(= η) | 学习率 | **一步迈多大** |
| `e` | 误差信号 | 现在错得多离谱;错得越狠,这步迈得越大 |
| `- reg * bU[u]` | 正则拉回 | 别把旋钮拧太极端,往 0 拉一把 |

### 2.4 两个超参:lr 和 reg

**学习率 lr(步长)**

| lr | 效果 | 比喻 |
|---|---|---|
| 太小 | 收敛极慢,训到天荒地老 | 下山一次只挪 1 毫米 |
| 刚好 | 平稳到达谷底 | 正常走路 |
| 太大 | 一步跨过谷底,来回震荡甚至发散 | 一步迈 10 米,冲过头摔下去 |

**正则 reg(橡皮筋)**

给每个参数拴一根"往 0 拉的橡皮筋"。参数越大,拉力越大。

- **作用**:防止某个旋钮被拧到极端值去过拟合(把训练数据背下来,但没泛化能力)。
- `- reg * 参数` 就是那根橡皮筋的力:参数越大,往回拉得越狠。

> ⚠️ 第 3 部会讲一个踩坑:reg 开太大,橡皮筋把所有隐向量都拉平到 0,模型退化成"只会预测平均分",排序能力归零。**旋钮不是越大越好。**

## 3. 把 MF 的一行更新完整翻译一遍

以 `bU[u] += lr * (e - reg * bU[u]);`(`MatrixFactorization.java:97`)为例:

```
b u +=    l r    * (    e        -    reg    * b u    )
│        │          │              │          │
│        │          │              │          └ 这个用户当前的偏置
│        │          │              └ 正则系数(橡皮筋的劲)
│        │          └ 误差 = 真实分 − 预测分
│        └ 学习率(步长)
└ 用户 u 的偏置旋钮
```

用人话读:**"用户 u 的打分偏置,朝'减小这次预测误差'的方向拧 lr 那么多;同时被正则往 0 拉一把。"**

再看隐向量的更新(`MatrixFactorization.java:104`):

```java
pu[f] += lr * (e * qif - reg * puf);
```

和上面唯一区别:`e`(标量误差)乘上了 `qif`(物品 i 在第 f 维的值)。

**为什么乘 `qif`?** 直觉:第 f 维这次"该出多大力",取决于对方(物品)在这一维有多强。对方这维是 0,你改了也白改;对方这维很强,你就该多改一点。这就是"链式法则"在推荐里的模样——**不用记,记住"梯度里出现对方的对应分量"即可**。

## 4. sigmoid 与概率(BPR 用得上)

第 4 部会看到 `σ(x_ui - x_uj) = 1 / (1 + exp(-(x_ui - x_uj)))`。它叫 **sigmoid**,作用只有一个:

> **把任意一个数(可正可负、可大可小)压进 0~1 之间,像"概率"。**

```text
       1.0 ┤           ╭────────      σ 很大 ≈ "几乎肯定"
           │         ╱
       0.5 ┤       ╱                  σ = 0.5 ≈ "猜不出"
           │     ╱
       0.0 ┤────╯                      σ 很小 ≈ "几乎否定"
           └──────┬──────┬──────►
                 -5     0     +5
```

在 BPR 里:

- 输入 `x_ui - x_uj` = "正样本比负样本高多少分";
- 输出 = "正样本真排在负样本前面的把握有多大";
- 把握越大(接近 1),损失越小。

**`-ln`(负对数)又是什么?** 它把"把握"变成惩罚:`把握=1` 时罚 0;`把握=0.5` 时罚一点点;`把握接近 0`(彻底搞错)时**罚到无穷大**。

> **生活比喻**:老师不允许你"既对又错"地蒙题——你越自信地答错,扣得越狠。这就是 `-ln σ(...)` 干的事:逼模型要么别猜、要么猜对,不许自信地猜错。

代码里对应 `BprMF.java:111` 的 `sigmoidNeg = 1.0 / (1.0 + Math.exp(z))`,它反过来表示"模型搞错的程度"(越接近 1 说明越该狠更新)。

## 5. 哪些数学你**不用**学(划重点)

阶段 1–3,**下面这些一个都用不上**,别被吓到:

- ❌ 微积分求导的证明、极限、泰勒展开
- ❌ 线性代数的矩阵特征值、行列式、秩、SVD 推导
- ❌ 概率论的公理、贝叶斯定理的推导、各种分布
- ❌ 凸优化、KKT 条件、拉格朗日乘子

你**真正需要**的,就是这部 §1–§4。

**什么时候才要补更深的数学?** 到读原始论文时,遇到哪个补哪个(比如读 BPR 论文时,再理解"最大后验估计"是什么意思)。**按需、就地**,而不是现在去啃一门高数课——那只会让你在半路放弃。

## 6. 一页速查卡(建议截图存手机)

| 符号 | 人话 | Java / 仓库对应 |
|---|---|---|
| `v = [0.5, -0.2, 0.8]` | 一排数 | `double[]` |
| `p · q = Σ p_f q_f` | 对应相乘再相加 = 相似度 | `dot()` 里的 for 循环 |
| `Σ` | 求和 = for 循环 | 到处 |
| `θ` | 所有可调参数的统称 | `p`、`q`、`bU`、`bI` |
| `L(θ)` | 一个数:现在错得多离谱,越小越好 | `e`、`sigmoidNeg` |
| `∂L/∂θ` | 旋钮拧大一点,损失变大还是变小 = 坡的朝向 | 更新公式括号里那一坨 |
| `θ ← θ − lr·(∂L/∂θ)` | 每个旋钮朝下坡挪一小步 | `+= lr * (...)` |
| `η` = `lr` | 一步迈多大 | 构造器参数 `lr` |
| `λ` = `reg` | 橡皮筋:把参数往 0 拉,防过拟合 | 构造器参数 `reg` |
| `μ` | 全局平均分 | `train.globalMean()` |
| `‖p‖²` | 向量每个数平方再相加 | `Σ p_f²` |
| `σ(x)` | 把任意数压到 0~1,像概率 | `1/(1+exp(-x))` |
| `x_ui > x_uj` | 正样本的分数 > 负样本 | BPR 的目标 |
